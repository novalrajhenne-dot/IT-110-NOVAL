The HTML DOM represents a webpage as a tree of elements. Each element can have a parent and child elements.

This section demonstrates how HTML elements are connected through parent and child relationships.

  • The main element is the parent of the section.
  • The section contains the heading and paragraph.
  • The list is the parent of the list items.
